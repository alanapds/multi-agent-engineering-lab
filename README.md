# Multi-Agent Engineering Lab

Plataforma experimental de agentes de Inteligência Artificial aplicada à Engenharia.

## Objetivo

Desenvolver, de forma incremental, uma arquitetura de agentes de IA capaz de receber tarefas, utilizar ferramentas, consultar dados, analisar informações técnicas e produzir resultados baseados em evidências.

## Versão atual

### v0.1 — Estrutura inicial do agente

Nesta primeira versão foi criada a estrutura básica de um agente de software em Python.

O agente atualmente:

* recebe uma tarefa;
* mantém um nome;
* processa a entrada;
* retorna uma resposta.

Nesta etapa ainda não foi integrada uma API de modelo de linguagem.

## Arquitetura atual

```text
Usuário
   │
   ▼
main.py
   │
   ▼
EngineeringAgent
   │
   ▼
Resposta
```
